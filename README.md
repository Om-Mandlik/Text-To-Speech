# Text-to-Speech Web App

A simple Text-to-Speech (TTS) web application built using HTML, CSS, and JavaScript. This project converts user-entered text into spoken audio using the Web Speech API available in modern browsers.

## Features

* Convert text into speech instantly
* Uses the browser's built-in Speech Synthesis API
* Simple and user-friendly interface
* Supports different system voices
* Lightweight and fast
* No external libraries required

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Usage

* Type any text into the input field.
* Click the **Read** button.
* Listen to the generated speech output.
